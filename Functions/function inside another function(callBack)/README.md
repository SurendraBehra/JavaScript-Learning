## Features
* Accepts a function as an argument.
* Executes the passed function two times.
* Demonstrates function reuse.
* Shows basic callback behavior in JavaScript.
* Prints output dynamically in the console.

## Concepts Used
* JavaScript Functions
* Higher-Order Functions
* Callback Functions
* Anonymous Functions
* Function Invocation
* Console Output (console.log())

## Code Logic Overview
* runTwice(fun)
    Takes a function as a parameter.
* fun()
    Executes the passed function.
* The function is called twice, so the same action repeats.
* An anonymous function is passed that logs "Hello".
