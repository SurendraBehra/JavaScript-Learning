## Features
- Demonstrates usage of `map()` for transforming array values
- Demonstrates usage of `filter()` for condition-based removal
- Shows how to work with numbers and strings in arrays
- Uses arrow functions and callbacks
- Prints results to the console

## Concepts Used
- JavaScript Arrays
- `map()` Method
- `filter()` Method
- Arrow Functions
- Callback Functions
- Conditional Logic
- Console Output (`console.log()`)

### Map Function (`addNum`)
- Takes an array of numbers and a number as input
- Uses `map()` to loop through each value
- Doubles each value in the array
- Returns a new transformed array

### Filter Function (`removeEgg`)
- Takes an array of food items
- Removes only the **first two occurrences** of `"egg"`
- Uses a counter to track removed eggs
- Returns the remaining items as a new array
