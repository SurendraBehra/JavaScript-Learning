## Features
- Displays an **Add to cart** button
- Shows message **"Added"** when button is clicked
- Automatically removes the message after **2 seconds**
- Demonstrates dynamic text display
- Uses JavaScript timer function

## Concepts Used
- HTML Button Element
- Paragraph (`<p>`) Element
- JavaScript DOM Manipulation
- `document.querySelector()`
- Inline Event Handler (`onclick`)
- `setTimeout()`
- Anonymous Functions
- `innerHTML`

## How to Run
1. Save the file as `index.html`
2. Open the file in any modern web browser
3. Click the **Add to cart** button
4. Message **"Added"** appears below the button
5. Message disappears automatically after 2 seconds

## Code Logic Overview
- `.message` selects the paragraph element
- `display()` function executes on button click
- `innerHTML` displays the text **"Added"**
- `setTimeout()` clears the message after 2000 milliseconds
