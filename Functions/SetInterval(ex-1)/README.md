## Features
- Displays a button with initial text "start"
- Changes button text to "finished!" after clicking
- Uses a time-based function to update content
- Demonstrates event handling and DOM manipulation
- Updates the UI dynamically

## Concepts Used
- HTML Button Element
- JavaScript DOM Manipulation
- document.querySelector()
- Event Listeners (addEventListener)
- Arrow Functions
- setInterval()
- innerHTML

## Code Logic Overview
- .finish selects the button element
- addEventListener listens for button clicks
- setInterval runs the function every 1000 milliseconds
- innerHTML updates the button text dynamically

## Learning Outcome
- Understanding event listeners
- Using timers in JavaScript
- Updating HTML dynamically
- Handling user interactions with DOM elements
