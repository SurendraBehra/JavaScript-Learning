## Features
* Two buttons: **Heads** and **Tails**
* Displays the user's selection instantly
* Demonstrates basic JavaScript functions
* Uses DOM manipulation with `querySelector()`
* Beginner-friendly project for learning HTML, CSS, and JavaScript interaction


## Concepts Used
* HTML Buttons
* JavaScript Functions
* DOM Manipulation
* `document.querySelector()`
* `innerHTML`
* Event Handling with `onclick`


## How to Run
1. Create a folder for the project.
2. Save the HTML code as `index.html`.
3. Save the JavaScript code as `script.js`.
4. Open `index.html` in any web browser.
5. Click either **Heads** or **Tails**.


## Example Output
When clicking **Heads**:
```text
you choose heads
```

When clicking **Tails**:
```text
you choose tails
```
