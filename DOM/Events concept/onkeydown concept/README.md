## Features
* Enter a name in a text input field.
* Submit the name by:
  * Clicking the **Submit** button.
  * Pressing the **Enter** key.
* Displays the entered name on the webpage.
* Demonstrates basic event handling in JavaScript.


## Concepts Used
* HTML Forms
* Input Elements
* JavaScript Functions
* DOM Manipulation
* `document.querySelector()`
* `value` Property
* `innerHTML`
* Keyboard Events (`onkeydown`)
* Button Click Events (`onclick`)


## How to Run
1. Save the code as `index.html`.
2. Open the file in any modern web browser.
3. Enter your name.
4. Press **Enter** or click **Submit**.
5. The entered name will be displayed below the input field.
